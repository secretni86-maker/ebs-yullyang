# 잉글리시 브레인 스튜디오 율량주성점 홈페이지

## 켜는 방법
`홈페이지_켜기.bat` 을 두 번 클릭 → 브라우저가 열립니다. (검은 창을 닫으면 꺼져요)
휴대폰에서 같은 와이파이로 보고 싶으면 `홈페이지_켜기_휴대폰용.bat`.

## 관리자 (원장님만)
주소 맨 끝에 `/admin` (예: http://localhost:8000/admin). 처음 한 번 비밀번호를 만들면, 그 비밀번호를 아는 사람만 고칠 수 있어요.
- **글쓰기**: 수업료·시간표·공지. 사진을 올리면 바로 보이고, 수정/삭제 버튼이 작게 붙어 있어요.
- **사진 자리 바꾸기**: 홈페이지 오른쪽 아래 `✎ 사진 바꾸기`를 켜고 사진 위 연필(✎)을 누르면 바로 교체.
- **수업 사진 모음 / 수업 영상 / 후기 / 학원 정보(이름·전화·주소·링크·색·로고)**.
- 사진·영상은 올릴 때 아이 얼굴을 자동 모자이크하고, 빠진 얼굴은 `가리기`로 직접 가릴 수 있어요.

## 폴더
- `data/content.json` : 모든 내용 저장 (관리자 화면에서 바뀜. 백업하려면 이 파일과 `media/` 폴더를 복사)
- `data/auth.json` : 관리자 비밀번호(암호화되어 저장). 비밀번호를 잊으면 이 파일을 지우고 `/admin`에서 새로 만들면 됩니다.
- `media/` : 사진·영상
- `server/defaults.py` : 처음 문구·사진 배치 (파일을 직접 고치고 싶을 때)
- `tools/` : 원본 사진·영상에 모자이크를 입혀 `media/`에 넣는 도구

## 인터넷에 공개하기 (GitHub Pages)
GitHub Pages 는 '보여주기만' 하는 정적 사이트입니다. 관리자 기능(글쓰기·사진 바꾸기)은 내 컴퓨터에서 쓰고,
고친 뒤 공개 사이트에 반영하려면:
1. `py tools/export_static.py` (공개용 파일을 `../_pages` 에 만듭니다)
2. `_pages` 폴더에서 `git add -A && git commit -m "update" && git push -f origin gh-pages`
